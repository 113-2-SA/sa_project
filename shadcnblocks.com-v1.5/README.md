# Shadcnblocks.com Pro Blocks

Thank you for purchasing Shadcnblocks.com Pro. This package includes hundreds of pro block components ready to copy/paste into your project.

* `/block` contains the pro blocks
* `tailwind.config.ts` is the default Tailwind config for Shadcn with a few extra properties for our blocks
* `global.css` is the default Tailwind CSS setup for Shadcn Themeing with a few extra classes for our blocks

When you copy and paste a block, you may need to install the dependencies and add the required Shadcn UI components. 

For example to use `Cta1.tsx` you would need to install the following.

`npm install --save lucide-react`

`npx shadcn@latest add button card`

Our blocks are setup to use the default values in the `components.json` that is generated by `npx shadcn@latest init`
